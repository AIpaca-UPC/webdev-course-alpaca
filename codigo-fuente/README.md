# Código fuente del curso

Esta carpeta contiene los ejemplos utilizados como apoyo para las lecciones de Fundamentos de Desarrollo Web.

## Estructura

- `leccion-1/index.html`: ejemplo de estructura HTML para reconocer el contenido de una página.
- `leccion-1/styles.css`: estilos CSS para observar cómo cambia la presentación visual sin modificar la estructura HTML.
- `leccion-2/index.html`: ejemplo de documento HTML con etiquetas, elementos y atributos básicos.

## Cómo utilizar los ejemplos

**En CodePen**

1. Abre https://codepen.io/pen/.
2. Para la lección 1, copia el contenido de `leccion-1/index.html` en el panel HTML.
3. Copia el contenido de `leccion-1/styles.css` en el panel CSS.
4. Para la lección 2, copia el contenido de `leccion-2/index.html` en el panel HTML.
5. Modifica los textos y observa los resultados en la vista previa.

**En tu computadora**

1. Descarga o clona el repositorio.
2. Abre la carpeta de la lección que deseas revisar.
3. Abre el archivo `index.html` en un navegador.
4. En la lección 1, conserva `styles.css` en la misma carpeta que `index.html` para que se apliquen los estilos.

No es necesario instalar un editor ni herramientas adicionales para visualizar los ejemplos.
