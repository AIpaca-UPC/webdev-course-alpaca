# Fundamentos de Desarrollo Web

Curso introductorio y práctico para estudiantes de secundaria. Aprenderás cómo se construye una página web y crearás tus primeros ejemplos utilizando HTML y CSS. **No necesitas experiencia previa ni instalar programas:** basta con un navegador web.

## Resumen del curso

| Información | Detalle |
|---|---|
| Duración total | Aproximadamente 60 minutos |
| Público objetivo | Estudiantes de 12 a 17 años |
| Nivel | Inicial, sin experiencia previa |
| Prerrequisitos | Ninguno |
| Herramientas | Navegador web, CodePen y JSFiddle |

**Repositorio del curso:**  
https://github.com/AIpaca-UPC/webdev-course-alpaca

**Código fuente de las prácticas:**  
La carpeta `codigo-fuente/` contiene los ejemplos HTML y CSS preparados para las lecciones 1 y 2. Consulta `codigo-fuente/README.md` para saber cómo utilizarlos.

## Objetivo general

Comprender los fundamentos del desarrollo web y crear páginas sencillas mediante HTML para estructurar el contenido y CSS para definir su presentación visual.

## Secuencia de las lecciones

## Secuencia de la lección


### Lección 1: ¿Qué es el desarrollo web? (5 minutos)
**Descripción:**
En esta lección aprenderemos qué es el desarrollo web, cómo funcionan los sitios web y cuál es la diferencia entre HTML y CSS.

**Video de la lección:** https://youtu.be/MhXyCLyGcX4

**Presentación de Canva:** https://canva.link/o86oovjtlv53guh

**Objetivos de aprendizaje:**
- Comprender qué es un sitio web.
- Identificar para qué sirven HTML y CSS.
- Diferenciar la estructura y la presentación visual de una página web.
- Observar una demostración práctica utilizando CodePen.

**Herramienta de práctica:** https://codepen.io/pen/

**Consejo clave:**
HTML organiza el contenido de una página web, mientras que CSS define su apariencia visual.

---

### Lección 2: Introducción a HTML (10 minutos)
**Descripción:**
En esta lección aprenderemos la estructura básica de HTML, el uso de etiquetas, elementos y atributos para construir nuestra primera página web.

**Video de la lección:** https://youtu.be/F_YXTLa8NuM

**Presentación de Canva:** https://canva.link/mkrexdeddkepg5i

**Objetivos de aprendizaje:**
- Reconocer la estructura básica de un documento HTML.
- Comprender la función de las etiquetas `html`, `head` y `body`.
- Utilizar encabezados `h1` y `h2`.
- Crear párrafos mediante la etiqueta `p`.
- Identificar atributos HTML y comprender para qué sirven.
- Crear y personalizar una página web sencilla.

**Herramienta de práctica:**
https://codepen.io/pen/

**Código fuente incluido en el repositorio:**
- `codigo-fuente/leccion-2/index.html`

**Consejo clave:**  
HTML permite estructurar y organizar el contenido de una página web mediante etiquetas y elementos.

---

---
### Lección 3: Añadir más elementos HTML (8 minutos)

**Descripción:**  
En esta lección aprenderemos a utilizar listas, imágenes y enlaces para crear páginas web más completas e interactivas.

**Video de la lección:** https://youtu.be/-j8tAkanq1Y

**Presentación de Canva:** https://canva.link/oeiijvaqxqf8vrr

**Objetivos de aprendizaje:**
- Comprender cómo funcionan las listas ordenadas y desordenadas.
- Utilizar las etiquetas `ul`, `ol` y `li` para organizar información.
- Insertar imágenes mediante la etiqueta `img` y sus atributos `src` y `alt`.
- Crear enlaces utilizando la etiqueta `a` y el atributo `href`.
- Desarrollar una página web sencilla utilizando JSFiddle.

**Herramienta de práctica:** https://jsfiddle.net/wv7fb4xh/4/

**Consejo clave:**  
HTML permite organizar contenido mediante listas, mostrar imágenes y conectar páginas utilizando enlaces.

---


### Lección 4: Introducción a CSS (12 minutos)

**Descripción**: Dale estilo a tu HTML con colores, fuentes y diseños.

**Video de la lección:** https://youtu.be/lE5zCoDd0gc

**Presentación de Canva:** https://canva.link/fxwlnjmmtwaf272

- **Consejos clave**: Vincular CSS, usar selectores como `body { background-color: blue; }`.

**Herramienta de práctica:** https://jsfiddle.net/b7Lscurv/1/

### Lección 5: Crear una página web sencilla (11 minutos)

**Descripción:**  
Integraremos los conocimientos de HTML y CSS para desarrollar una página de perfil personal.

**Objetivos de aprendizaje:**
- Organizar el contenido de una página utilizando HTML.
- Aplicar estilos mediante CSS.
- Personalizar textos, colores y distribución.
- Revisar y corregir errores básicos.

**Proyecto práctico:**  
Pendiente de incorporación.

**Consejo clave:**  
Una página web sencilla puede construirse combinando una estructura HTML clara con estilos CSS.

**Herramienta de práctica:**

**Código fuente incluido en el repositorio:**

### Lección 6: Consejos y próximos pasos (10 minutos)

**Descripción:**  
Revisaremos buenas prácticas, errores frecuentes y recursos para continuar aprendiendo desarrollo web.

**Objetivos de aprendizaje:**

- Comprender la importancia de mantener un código ordenado.
- Identificar recursos para seguir practicando.
- Reconocer la documentación de MDN como material de consulta.

**Presentación de Canva:**

https://codepen.io/pen/

**Consejo clave:**  
La práctica constante y la revisión del código ayudan a mejorar nuestras habilidades de desarrollo web.
