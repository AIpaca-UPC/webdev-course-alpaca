# 🌐 Fundamentos de Desarrollo Web

> **Tu primer paso para crear páginas web con HTML y CSS.** Aprende los conceptos básicos y construye tu primera página desde el navegador.

## 👋 Sobre el curso

Este curso introductorio de **60 minutos** está dirigido a estudiantes de secundaria que desean conocer cómo se construyen los sitios web. No necesitas experiencia previa ni instalar programas: solo utiliza un navegador.

| Información | Detalle |
|---|---|
| **Duración** | 60 minutos |
| **Público objetivo** | Estudiantes de 12 a 17 años |
| **Nivel** | Inicial — sin experiencia previa |
| **Prerrequisitos** | Ninguno |
| **Herramientas** | Navegador web: Chrome, Firefox, Safari o Edge |

## 🎯 ¿Qué aprenderás?

Al finalizar el curso podrás:

- Explicar qué es un sitio web y cómo se organiza.
- Reconocer la función de HTML y CSS.
- Crear contenido utilizando títulos, párrafos, listas, imágenes y enlaces.
- Aplicar estilos para mejorar la presentación de una página.
- Combinar HTML y CSS en una página de perfil personal.

## 🧰 Herramientas del curso

No necesitas descargar un entorno de desarrollo. Trabajaremos directamente desde el navegador:

- [CodePen](https://codepen.io/pen/) — para experimentar con HTML y CSS.
- [JSFiddle](https://jsfiddle.net/) — para ejecutar y probar fragmentos de código.
- [Replit](https://replit.com/) — para organizar el proyecto final en archivos.

> **¿Dónde está el código?** Las plantillas iniciales de las cinco actividades están en la [guía de prácticas](practicas/README.md). Los editores pueden abrir un espacio en blanco: copia en ellos el código de la actividad correspondiente.

## 📚 Secuencia de las lecciones

### 01. ¿Qué es el desarrollo web? — 5 minutos

**Descripción:** conocerás qué es el desarrollo web, cómo funcionan los sitios y cuál es la diferencia entre HTML y CSS.

**Objetivos de aprendizaje**
- Comprender qué es un sitio web.
- Identificar para qué sirven HTML y CSS.
- Diferenciar la estructura y la presentación visual de una página.
- Observar una demostración práctica utilizando CodePen.

**Recursos**
- 🎥 [Ver video de la lección](https://youtu.be/MhXyCLyGcX4)
- 📊 [Abrir presentación de Canva](https://canva.link/o86oovjtlv53guh)
- 💻 [Ver plantilla de práctica](practicas/README.md#leccion-1) · [Abrir CodePen](https://codepen.io/pen/)

> **Idea clave:** HTML organiza el contenido de una página web, mientras que CSS define su apariencia visual.

---

### 02. Introducción a HTML — 10 minutos

**Descripción:** aprenderás la estructura básica de HTML y el uso de etiquetas, elementos y atributos para construir tu primera página web.

**Objetivos de aprendizaje**
- Reconocer la estructura básica de un documento HTML.
- Comprender la función de las etiquetas html, head y body.
- Utilizar encabezados h1 y h2.
- Crear párrafos mediante la etiqueta p.
- Comprender el uso de los atributos HTML.
- Crear y personalizar una página web sencilla.

**Recursos**
- 🎥 [Ver video de la lección](https://youtu.be/F_YXTLa8NuM)
- 📊 [Abrir presentación de Canva](https://canva.link/mkrexdeddkepg5i)
- 💻 [Ver plantilla de práctica](practicas/README.md#leccion-2) · [Abrir CodePen](https://codepen.io/pen/)

> **Idea clave:** HTML permite estructurar y organizar el contenido de una página web mediante elementos y etiquetas.

---

### 03. Añadir más elementos HTML — 8 minutos

**Descripción:** aprenderás a utilizar listas, imágenes y enlaces para crear páginas web más completas.

**Objetivos de aprendizaje**
- Comprender cómo funcionan las listas ordenadas y desordenadas.
- Utilizar las etiquetas ul, ol y li para organizar información.
- Insertar imágenes mediante la etiqueta img y sus atributos src y alt.
- Crear enlaces utilizando la etiqueta a y el atributo href.
- Practicar la incorporación de estos elementos en una página web.

**Recursos**
- 🎥 [Ver video de la lección](https://youtu.be/-j8tAkanq1Y)
- 📊 [Abrir presentación de Canva](https://canva.link/oeiijvaqxqf8vrr)
- 💻 [Ver plantilla de práctica](practicas/README.md#leccion-3) · [Abrir actividad en JSFiddle](https://jsfiddle.net/wv7fb4xh/4/)

> **Idea clave:** las listas organizan información, las imágenes enriquecen el contenido y los enlaces conectan páginas.

---

### 04. Introducción a CSS — 12 minutos

**Descripción:** aprenderás a dar estilo a una página HTML mediante colores, fuentes, tamaños y distribución de elementos.

**Objetivos de aprendizaje**
- Reconocer la función de CSS en una página web.
- Identificar selectores y reglas CSS.
- Aplicar colores, tipografías y fondos.
- Modificar márgenes, espacios y bordes para mejorar la presentación.

**Recursos**
- 🎥 Video y presentación: **pendientes de publicar**.
- 💻 [Ver plantilla de práctica](practicas/README.md#leccion-4) · [Abrir CodePen](https://codepen.io/pen/)

> **Idea clave:** CSS controla la presentación visual y permite personalizar el contenido estructurado con HTML.

---

### 05. Crear una página web sencilla — 15 minutos

**Descripción:** combinarás HTML y CSS para construir una página de perfil personal.

**Objetivos de aprendizaje**
- Integrar la estructura HTML con estilos CSS.
- Organizar información personal en secciones.
- Personalizar textos, imágenes, colores y botones.
- Revisar y corregir errores básicos de presentación.

**Recursos**
- 🎥 Video y presentación: **pendientes de publicar**.
- 💻 [Ver plantilla del proyecto](practicas/README.md#leccion-5) · [Abrir Replit](https://replit.com/)

> **Proyecto final:** crea una página de perfil sencilla y personalízala con tus propios contenidos de ejemplo.

---

### 06. Consejos y próximos pasos — 10 minutos

**Descripción:** revisarás buenas prácticas, errores frecuentes y recursos para continuar aprendiendo desarrollo web.

**Puntos clave**
- Revisar la escritura y estructura del código.
- Comprobar que las imágenes y los enlaces funcionen.
- Mantener el contenido organizado y fácil de leer.
- Seguir practicando con la documentación de desarrollo web.

**Recurso recomendado**
- 📖 [Documentación web de MDN en español](https://developer.mozilla.org/es/)

**Video y formulario de entrega:** pendientes de publicar.

> **Consejo final:** la mejor manera de aprender desarrollo web es practicar, experimentar y mejorar tus propios proyectos.
